
# EpicFight AnimationPhysics Library
Using [Libbulletjme](https://github.com/stephengold/Libbulletjme)  as the physics backend.

# **Warning**
It just has a windows platform pre-build binary lib file in this project. 

If you want to use in other platform, please build Libbulletjme binary file with ReleaseSpMt(single float point multi-threading) version by yourself. Named in format: {Windows64/Linux64/MacOSX64}ReleaseSpMt_bulletjme.{dll/so/dylib} at path /assets/ef_skin/physics_native_lib/

Example(windows platform): /assets/ef_skin/physics_native_lib/Windows64ReleaseSpMt_bulletjme.dll
